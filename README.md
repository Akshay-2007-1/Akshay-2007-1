## Projects

- [O(1) Exchange](https://github.com/Akshay-2007-1/o1-exchange-engine): a limit order book and matching engine in C++, with a React dashboard on top. It was my Orbital 2026 project. There's a [live demo](https://o1-exchange-engine.vercel.app).
- [TechTokers](https://github.com/Akshay-2007-1/TechTokers): our TikTok TechJam 2026 entry. It's a layer that sits around coding agents and decides what they may do before a run, limits them while they run, and checks what they changed afterwards.
- [omarchy-storage-drilldown](https://github.com/Akshay-2007-1/omarchy-storage-drilldown): a bar widget for Omarchy that shows disk usage and lets you click into folders to see where the space went.
- [Split-It](https://github.com/Akshay-2007-1/SplitWise_spinoff): a Splitwise-style Android app in Kotlin. It was my first app, made with a friend.
- [roleplay](https://github.com/Akshay-2007-1/roleplay): a roleplay engine that keeps its state in markdown files, so the cost of each turn stays flat however long the story gets.

A few things are in private repos for now, mainly a memory system for AI characters and a browser game based on a news story.
