# Akshay Vemulapalli

CS undergrad at NUS, based in Singapore. I like systems, small tools that do one thing properly, and fixing things in codebases I didn't write.

Most of my time goes to three things at the moment:

- **Open source.** I've been working on EV3 robot support for [Source Academy](https://github.com/source-academy): Python on the brick through `pynter-ev3`, the frontend and language-directory wiring, and a lot of docs for `ev3-source`. I've also sent patches to SQLFluff.
- **Shipd.** I build benchmark tasks out of real issues in open-source projects (PostCSS, Browserslist, Cython, SQLFluff and others): a failing test, a reference fix, and a Docker harness that proves both. I also wrote a small pipeline to keep track of it all, since doing it by hand got messy fast.
- **Whatever's next.** Usually a side project that got out of hand.

## Things I've built

- [o1-exchange-engine](https://github.com/Akshay-2007-1/o1-exchange-engine): a C++ limit order book and matching engine with a live React dashboard. Price/time priority, WebSocket feed, and a toggle that swaps the bitmap engine for a plain `std::map` one so you can watch the difference. Made for NUS Orbital 2026. [Live demo](https://o1-exchange-engine.vercel.app).
- [TechTokers](https://github.com/Akshay-2007-1/TechTokers): TikTok TechJam 2026 entry. A control layer for coding agents that checks what they're allowed to do before a run, limits them during it, and verifies what they changed on disk afterwards.
- [omarchy-storage-drilldown](https://github.com/Akshay-2007-1/omarchy-storage-drilldown): a bar widget for Omarchy. Click the disk icon, then click through folders to see what's eating your space and by how much.
- [SplitWise_spinoff](https://github.com/Akshay-2007-1/SplitWise_spinoff): our first Android app, an expense splitter in Kotlin and Compose.
- [CSES](https://github.com/Akshay-2007-1/CSES): competitive programming solutions in C++, added to whenever I get the itch.

Some other stuff lives in private repos: a long-term memory benchmark for an AI companion, and a browser game about a real piece of reporting on elephant compensation in West Bengal.
